# Recode Pro IA - Projeto Agência de Viagens

## Página Web sobre Agência de Viagens ficticia, em desenvolvimento no curso da Recode Pro IA, contendo HTML, CSS, Bootstrap e Banco de Dados.

### Nesta primeira etapa, desenvolvi uma solução inicial para uma agência de viagens fictícia, estruturando tanto a interface quanto o planejamento do banco de dados. O objetivo é criar uma base sólida para o projeto, alinhada às melhores práticas de desenvolvimento web.
